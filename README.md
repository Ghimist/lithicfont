# `lithicfont` 碑碣字型庫

## 序言
夫文以載道，字以凝脈。昔者結繩既遠，倉頡演爻；鼎彝銘功，碑碣紀德。
今也數碼宏開，寰宇同網。然古籍幽奧，字模繁蕪；編碼之理，宛若河圖。
乃作 `lithicfont`，鍊泰西之精鐵（Rust），鐫上古之玄文。
探字型之微眇，運工巧於毫端。

* **疾如激電，固若崇山**：秉 Rust 之剛健，剖 TTF 之精微。記憶無漏，指針不迷。
